# Diagnostic Instruments

CPU, Memory, GPU, Storage, Network and Processes are diagnostic instruments.

They should prioritize:

• precision
• readability
• density
• consistency

They are not decorative components.

Do not reinvent proven monitoring patterns simply to appear different.

Innovation should focus on understanding rather than novelty.

# Visual Hierarchy

Only one component may dominate visual attention.

That component is System Pulse.

Everything else should remain visually quiet.

Metrics should never compete with the Pulse.

They should explain it.

# Familiarity Wins

Developers already understand the visual language of mature system monitors.

CPU meters.

Memory bars.

Storage usage.

Process tables.

These conventions should be preserved whenever they improve readability.

Familiarity reduces cognitive load.
